# Fibre

Real connections. Physical signal pathways. The wiring that carries bithzs.

## What counts as Fibre

- Neural axons carrying action potentials
- Grammar rules constraining token selection
- Data structures holding typed nodes
- Edges in BioChain: → ⊣ ~> => |>
- xgrammar EBNF production rules
- The bee's flight path from flower to hive

Fibre is measurable. You can trace it. You can verify it.
If it parses, it's Fibre. If it doesn't, it's noise.

## Fibre in BioChain

Every chain in BASE is Fibre:
```
{L.nt:DA[+]@VTA}→{R:D1(Gs)@NAc}→{Gp:Gs@NAc}→{2m:cAMP@NAc}→{K:PKA@NAc}
```

Each → is a fibre. Each node is a junction. The cascade tag names the fibre type.
