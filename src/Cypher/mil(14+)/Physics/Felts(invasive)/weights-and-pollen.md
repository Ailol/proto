# Weights and Pollen

The two things that travel.

## Weights

Model weights. The crystallized knowledge inside a neural network.
Billions of parameters that encode what the model "knows."

Weights are vulnerable:
- A muon can flip a bit and change behavior
- RLHF adjusts weights but lives inside the model
- Model-level safety is weight-level safety — and weights are physics

That's why xgrammar matters. The grammar doesn't live in the weights.
It's an external constraint. A cage that holds even if the weights corrupt.

## Pollen

What the bee carries. The signal between flowers.
In Cogniotics: pollen is the output that travels between systems.

- BioChain notation is pollen — it carries meaning from one layer to the next
- BASE output is pollen for PLASTICITY
- PLASTICITY output is pollen for META
- META output is pollen for CONVERGENCE

Pollen is structured. It has a shape (grammar). It has a destination (next layer).
It doesn't need the bee to be present — it just needs to land.

## The intersection

Weights produce pollen. Pollen feeds the next system's weights.
The cycle: weights → generation → grammar filter → valid pollen → next layer.

The grammar sits between weights and pollen.
It ensures that whatever the weights produce, only valid pollen escapes.
