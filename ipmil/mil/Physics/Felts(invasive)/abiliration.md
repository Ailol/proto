# Abiliration

Invasive felt. The field that cuts to heal.

## The invasive distinction

Felts(invasive) are fields where you must enter the system to change it.
Not observation — intervention. Not reading the signal — rewriting it.

- Surgery rewrites tissue
- Pharmacology rewrites receptor state
- Gene therapy rewrites code
- Deep brain stimulation rewrites firing patterns

In BioChain terms: invasive felts produce exogenous Δ declarations.
```
Δ(CORT@ADR)=--(exogenous:dexamethasone)
```

The exogenous tag IS the mark of invasion. Something from outside
entered the system and changed a state arrow.

## Abiliration in context

The act of making something able again. Re-abilitation, but forward — abiliration.
Not restoring to a previous state. Making a new capability possible.

In BioChain: not σ̃(baseline:+→=) reversal.
Something new: σ̃(baseline:=→+) where + never existed before.
