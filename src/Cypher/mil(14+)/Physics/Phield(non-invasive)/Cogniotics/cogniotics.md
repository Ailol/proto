# Cogniotics

The field of condensing cognition into formal signal topology via AI-constrained grammars.

cognition + bio-iotics. Biotical treatment for cognition.

## Why the name

Welcoming. Someone walks up and sees *cognition* in the name. They know they belong.
Like DSM gives psychiatry a coordination point, Cogniotics gives the field a shared name.
Not borrowed authority from semiotics or biosemiotics. New field, new word.

## What it is

Clinical prose is gaseous — high entropy, infinite ways to say the same pathology.
Cogniotics condenses that gas into crystallized formal notation.
Every chain terminates. Every node is typed, coded, stated, and located.
The grammar is the truth test. Either it parses or it doesn't.

## Thermodynamic principle

- Gaseous state = unstructured clinical language
- Condensation = grammar constraints + AI generation (reducing microstates via EBNF)
- EE rest state = entropy-enthalpy equilibrium. The diamond closes. The system rests.

## Structure

- **Universal layer** = xgrammar (EBNF constrained decoding) — token-level safety, "ain't AI"
- **Behavioral layer** = Compact Cognit' (CCDSL) — rules for models without constrained decoding
- **Domain layer** = BioChain (first domain) — clinical biochemistry vocabulary

## The pipeline

BASE → PLASTICITY → META → CONVERGENCE

Snapshot → change → program → closure. Four layers, one diamond.
