# bithzs

The smallest unit of signal in the Fibre layer.

Not a bit. Not binary. A bithz — the irreducible quantum of biological information
that travels through real, physical pathways.

## What makes a bithz

A bithz is a signal that:
- Has a source (a node that fired)
- Has a direction (an edge it travels)
- Has a state (how loud it is right now)
- Has a fate (where it ends up)

It is the smallest thing the chain language can describe.
Below bithzs, there is only noise.

## bithzs vs bits

| | bit | bithz |
|---|-----|-------|
| Domain | Digital | Biological |
| Values | 0 or 1 | ++ + = ~ - -- X * |
| Path | Wire | Fibre |
| Fate | Stored or lost | Recycled, cleared, sequestered, consumed |
| Grammar | Boolean | Chain language |

A bit is dead or alive. A bithz has mood.

## In the chain language

```
{ENZ:CYP2D6[++]@liver} → {MET:dextromethorphan[-]@plasma}
```

The `++` and `-` are bithzs. They carry the signal's state through the chain.
The grammar ensures every bithz has exactly one of the valid states.
No ambiguity. No "maybe active." Either `++` or `+` or `=` — pick one.

## Why it matters

When a muon flips a model weight, the model might hallucinate a state.
But the grammar only allows valid bithzs. The constraint is external.
The bithz survives because the grammar survives.
